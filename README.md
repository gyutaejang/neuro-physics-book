# 뇌를 읽는 이공계 기초 교과서 시리즈

임상 신경심리학자가 뇌영상 박사과정에 필요한 물리, 화학, 생리를 **중고등 수준부터** 다시 쌓기 위한 한국어 교과서입니다.
수학은 별도 시리즈로 다룹니다. 완성된 PDF는 [`dist/`](dist/)에 있습니다.

## 로드맵

권 번호는 읽는 순서입니다. 뒤 권은 앞 권의 개념을 그대로 가져다 씁니다.

| 순서 | 책 | 내용 | 뇌영상과의 연결 | 상태 |
|---|---|---|---|---|
| 1 | **물리 1: 고전 물리와 전기** | 단위와 크기, 운동과 힘, 에너지, 진동과 파동, 열과 확산, 전기장과 전위, 회로, 자기와 전자기 유도, 빛 | 막전위, 케이블 이론, EEG 쌍극자, TMS 유도, MEG, DTI의 확산, fNIRS | 집필 중 |
| 2 | **화학 1: 생명을 위한 일반화학** | 원자와 결합, 물과 용액, 농도와 삼투, 산과 염기, 평형과 자유에너지, 산화환원, 생체분자 | 이온 농도와 네른스트 식, 혈액 산소 운반, MRS 대사물, 신경전달물질, 조영제와 추적자 | 예정 |
| 3 | **생리 1: 뉴런에서 혈류까지** | 세포와 막, 막 수송, 활동전위, 시냅스, 신경교, 뇌 에너지 대사, 뇌혈관과 혈류 조절, 신경혈관 결합, 뇌척수액 | BOLD 신호의 생리적 기원, PET의 FDG 대사, ASL 관류, 확산 MRI의 조직 구조 | 예정 |
| 4 | **물리 2: 현대물리와 영상의 물리** | 원자와 핵, 스핀과 자기공명, 이완(T1, T2, T2*), 방사선과 감쇠, 푸리에 변환과 신호처리, k-공간과 영상 형성 | MRI/fMRI/DTI 영상 형성, PET/CT, EEG/MEG 역문제 | 예정 |

물리 1과 화학 1은 서로 독립적이라 어느 쪽부터 읽어도 됩니다. 생리 1은 두 권 모두에 기댑니다. 물리 2는 앞의 세 권과 수학 시리즈(복소수, 미적분, 선형대수)를 전제로 합니다.

## 빌드

```bash
pip install -r tools/requirements.txt
(cd tools && npm install)
python3 tools/build.py physics-1 --preview
```

집필 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.
